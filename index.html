    Export

    Every entry, one row each. Opens in Excel or readr::read_csv().

    Everything: entries, categories, charts, work schedule and Money tab. Your data lives only on this device, so save one regularly (e.g. to iCloud Drive or Google Drive). Restore it with Import → Replace all.

    Import

    CSV format

    Columns: date, amount (required), plus optional type, category, description. Column names aren't case-sensitive.

    • Dates can be 2026-10-16, 10/16/2026 or 10/16/26.
    • No type column? Negative amounts become expenses, positive become income (handy for bank exports).
    • Unknown categories are created automatically; blank ones go to Misc.
    • Merge skips rows that exactly match an existing entry, so re-importing the same file won't double up.
